# 🧠 성격유형검사 프로그램 (Personality Type Test)

## 1. 프로젝트 소개

이 프로젝트는 Python으로 개발한 간단한 성격유형검사 프로그램입니다. 사용자가 여러 질문에 답변하면 응답에 따른 점수를 계산하여 성격유형을 판별하고, 해당 유형의 특징을 안내합니다.

MBTI와 유사한 4가지 성격 지표를 활용하여 총 16가지 성격유형을 구분합니다.

본 프로그램은 Python의 기초 문법, 조건문, 반복문, 자료구조 및 함수 활용을 학습하기 위한 개인 프로젝트입니다.

## 2. 주요 기능

- **성격유형 검사:** 질문에 대한 사용자 응답 수집
- **점수 계산:** 응답에 따라 성격 지표별 점수 누적
- **유형 판별:** 4가지 성격 지표를 조합하여 16가지 유형 중 하나 도출
- **결과 안내:** 판별된 성격유형과 특징 설명 제공
- **입력값 검증:** 잘못된 입력에 대한 재입력 안내
- **점수 확인:** 각 성격 지표의 점수 비교

## 3. 성격유형 판별 기준

| 성격 지표 | 유형 1 | 유형 2 | 설명 |
|---|---|---|---|
| 에너지 방향 | E | I | 외향형 / 내향형 |
| 정보 인식 | S | N | 감각형 / 직관형 |
| 의사결정 | T | F | 사고형 / 감정형 |
| 생활 방식 | J | P | 판단형 / 인식형 |

각 지표에서 선택된 유형을 조합하여 다음과 같은 16가지 유형을 판별합니다.

`ISTJ`, `ISFJ`, `INFJ`, `INTJ`, `ISTP`, `ISFP`, `INFP`, `INTP`, `ESTP`, `ESFP`, `ENFP`, `ENTP`, `ESTJ`, `ESFJ`, `ENFJ`, `ENTJ`

## 4. 프로젝트 구조

현재 기본형 프로그램은 별도의 외부 라이브러리 없이 하나의 Python 파일로 구성됩니다.

```text
personality-type-test/
├── personality_test.py   # 성격유형 검사 실행 및 결과 출력
└── README.md             # 프로젝트 소개 및 사용 설명서
```

### 파일 설명

- `personality_test.py`: 질문 목록, 성격유형 설명, 점수 계산, 유형 판별 및 결과 출력 기능을 포함합니다.
- `README.md`: 프로젝트 목적, 기능, 실행 방법 및 개발 정보를 설명합니다.

## 5. 개발 환경

- **언어:** Python 3
- **필요 라이브러리:** Python 표준 기능만 사용
- **실행 환경:** Windows, macOS, Linux의 Python 실행 환경

별도의 외부 패키지를 설치하지 않아도 실행할 수 있습니다.

## 6. 실행 방법

### 1단계. 저장소 복제

```bash
git clone <저장소_URL>
cd personality-type-test
```

`<저장소_URL>`은 본인의 GitHub 저장소 주소로 변경합니다.

### 2단계. 프로그램 실행

```bash
python personality_test.py
```

운영체제나 Python 설치 환경에 따라 다음 명령어를 사용할 수도 있습니다.

```bash
python3 personality_test.py
```

### 3단계. 검사 진행

1. 화면에 표시되는 질문을 확인합니다.
2. 각 질문에 대해 `1` 또는 `2`를 입력합니다.
3. 모든 질문에 답변하면 성격유형이 출력됩니다.
4. 결과 설명과 지표별 점수를 확인합니다.

## 10. 유의 사항

본 프로그램은 교육 및 오락 목적으로 제작된 간단한 성격유형검사입니다. 공식 MBTI 검사와 동일하지 않으며, 전문적인 심리 평가나 진단을 대체하지 않습니다.

검사 결과는 사용자의 성격을 확정적으로 규정하는 것이 아니라 자기 이해를 위한 참고 자료로 활용할 수 있습니다.
